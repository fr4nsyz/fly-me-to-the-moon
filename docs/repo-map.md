# Repository map

Generated by `tools/gen_repo_map.py`. Do not edit by hand.
Run `python tools/gen_repo_map.py` to regenerate, or
`python tools/gen_repo_map.py --check` to fail if this file is stale.

The tree has five parts: the pass rewrites float operations, the runtime
executes and corrupts them, the analyzer recomputes and compares, the
workloads are what get corrupted, and the tools build and drive it all.
