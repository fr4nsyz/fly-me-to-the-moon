# Project instructions

Read `STATE.md` before doing anything in this repository. It holds the current state of the work, the measurements already taken, the open decisions, and the next move.

Do not edit `docs/architecture-v1.md`. It is the frozen original. Edit `docs/architecture.md` and record every architectural change in `docs/audit-log.md`: add an entry for a new decision, or rewrite the existing entry when a decision changes (git history keeps earlier versions).

## Implementation workflow
- Suggest first: For any code, file creation, or edits, I'll show you proposed diffs or full code blocks with a brief explanation of what and why.
- No silent writes: I will not apply changes until you explicitly approve them.
- Approval required: Reply with "approve", "yes", an edited version, or questions. I'll only apply after that.
- Keep it transparent: If multiple files are involved, I'll lay them all out clearly for you to review.
